# Съёмка ролика для README

Ролик не записывается с экрана и не монтируется руками: он собирается из
следа Playwright, поэтому меняется вместе с плагином и не может показать то,
чего уже нет.

```bash
cd demo
npm install
npx playwright install chromium
npm run record   # прогон по сценарию demo.spec.ts, пример поднимается сам
npm run cut      # docs/demo.mp4 и docs/demo.gif
```

Нужен `ffmpeg` в PATH.

Подписи задаются вызовами `narrate()` прямо в сценарии — они же становятся
субтитрами. Наезд, курсор и вспышка на клике добавляются при сборке
(`cut.mjs`), сама страница о съёмке ничего не знает.

Всё это держится отдельным проектом со своими зависимостями: у самого пакета
их ноль, и так и должно остаться.
