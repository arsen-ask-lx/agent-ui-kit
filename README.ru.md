**Ткните в элемент работающего приложения, скажите что не так — заметка ляжет
в файл, который читает ваш агент.**

![Alt + клик по элементу, текст, Enter](https://raw.githubusercontent.com/arsen-ask-lx/agent-ui-kit/main/docs/demo.gif)

Между «вот эта кнопка» и `Rail.tsx:69` кто-то должен построить мост. Без него
любой разговор об интерфейсе состоит из описаний словами, а слова читаются
двумя способами.

Это плагин к Vite: он живёт в дев-сервере, и в исходниках проекта не нужно
ничего подключать.

```bash
npm i -D agent-ui-kit
```

```js
// vite.config.js
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import { agentUiKit } from "agent-ui-kit";

export default defineConfig({
  plugins: [react(), agentUiKit()],
});
```

Это вся установка. Зажмите **Alt** — элемент под курсором подсветится.
Клик — откроется поле. Наберите, нажмите **Enter**.

Посмотреть до установки — склонировать и запустить пример:

```bash
git clone https://github.com/arsen-ask-lx/agent-ui-kit && cd agent-ui-kit
npm install && npm run example
```

```markdown
## список каналов уезжает под профиль вместо прокрутки

- **where:** `ChatScreen › Rail › RoomList › SidebarSection`
- **what:** `<button>` — «Каналы»
- **classes:** `flex min-w-0 flex-1 items-center gap-1 rounded px-2.5 py-1 …`
- **page:** `/c/01a0814d-3bd0-708e-bed0-b1be60d2bbee`
- **when:** 2026-09-08 18:20:30
```

Дальше вы говорите агенту: *«пройди по NOTES.md»*. Цепочки компонентов
вместе со списком классов хватает, чтобы найти строку в исходнике одним
поиском.

## Почему файл, а не MCP-сервер

MCP-сервер означал бы либо опрос со стороны агента, либо ещё одну службу,
которую надо держать запущенной. Файлу не нужно ни то, ни другое: агент
читает его, когда смотрит, и **любой** агент это умеет — Claude Code, Cursor,
Codex, Copilot или человек с `git diff`. Ничто здесь не привязано к одному
поставщику.

Вы проходите по экрану и оставляете десять заметок подряд; никто не должен
ждать обработки каждой. Файл копит, агент потом идёт по списку.

## Настройки

```js
agentUiKit({
  file: "NOTES.md",   // куда копятся заметки
  key: "alt",         // "alt" | "ctrl" | "meta"
  color: "#e5484d",   // цвет подсветки
  placeholder: "что не так? Enter — сохранить, Esc — отменить",
  route: "/__agent-ui-kit",  // менять только при столкновении
})
```

## Что читается с элемента

- **цепочка компонентов** — из собственных фиберов React на DOM-узле
  (`ChatScreen › Rail › RoomList`). Только React и только в дев-режиме;
- **тег, классы, `id`, `data-testid`, немного текста** — для всего остального
  и для любого другого фреймворка.

Если имён компонентов найти не удалось, заметка всё равно записывается — с
тегом, классами и текстом. Оснастка, умирающая вместе с чужой
недокументированной подробностью, хуже, чем никакой оснастки.

## Только дев-режим

Плагин объявляет `apply: "serve"`. Клиент внедряется дев-сервером как
виртуальный модуль: в исходниках нечего подключать и нечего не забыть
вырезать из сборки.

## Три вещи, добытые дорогой ценой

Они лежат в исходниках комментариями, и они же — причина, по которой это
пакет, а не фрагмент кода:

- **никаких `prompt()` / `confirm()`** — родное окно браузера замораживает
  страницу и ломает любую автоматизацию, которая ведёт браузер снаружи;
- **клик с модификатором целиком принадлежит плагину** — иначе заметка о
  кнопке заодно эту кнопку нажимает;
- **поле закрывается по клику снаружи, а не по `blur`** — `blur` срабатывает
  раньше, чем успевает Enter, и съедал набранное.
